# Wing Feather Tool

A procedural Houdini toolset for building and managing structured wing-feather arrangements.

## Overview

The Wing Feather Tool was developed to automate the creation and control of layered feather structures on wings.

The workflow provides procedural controls for feather placement and deformation while packaging the underlying setup into reusable Houdini Digital Assets.

## Features

- Procedural wing-feather generation
- Structured feather placement
- Layered feather organization
- Artist-facing HDA controls
- Procedural deformation workflow
- Reusable feather setups
- Integration with the broader feather pipeline

## Houdini Digital Assets

Related HDAs include:

- `wing_feather.hda`
- `wing_feather_deformed.hda`

The assets separate the procedural wing-feather setup from the deformed feather workflow.

See [`otls/`](../../../../otls/) for the packaged assets.
